# Запуск агента «Монитор авиарынка»

Шаги 1–6 — базовая установка OpenClaw (по гайду vasilevanatali/openclaw-installer с поправкой
про Node.js). Шаги 7–10 — специализация под мониторинг.

## Поправка к исходному гайду

Сейчас OpenClaw требует **Node.js 24.16+ или 26.1+** (`package.json` → `engines.node`:
`>=24.16.0 <25 || >=26.1.0`). Совет из гайда «хватит Node 22» устарел.
Проще ставить официальным установщиком — он сам поставит нужную версию Node:
`curl -fsSL https://openclaw.ai/install.sh | bash`.

## 1–6. База

1. Сервер в ЕС: Ubuntu 22.04+, 2 ядра / 2 ГБ памяти / 20 ГБ диска.
2. Вход по SSH-ключу, вход по паролю отключить.
3. Установить OpenClaw (команда выше) → `openclaw onboard --install-daemon`.
4. Бот в @BotFather → токен; свой Telegram ID через @userinfobot.
5. «Мозг» — вход по подписке (ChatGPT через Codex или Claude через `claude setup-token`).
6. Канал Telegram, писать боту может только твой ID; проверить, что бот отвечает.

## 7. Проверить, доступны ли источники с сервера ← САМОЕ ВАЖНОЕ

```bash
mkdir -p ~/aviation-monitor && cd ~/aviation-monitor   # сюда скопировать файлы комплекта
python3 collector.py check
```
Что не открывается — удалить из `sources.json` или заменить. Если сайты ведомств закрыты
для зарубежных адресов, есть два варианта: брать их новости через поиск (уже заложено,
строки «через поиск») или поставить сборщик на маленький российский сервер.

## 8. Список компаний

Заполнить `watchlist.csv` (разделитель `;`). Колонки:
`компания; синонимы (через запятую); тип; выручка_2024_млн_руб; активы_в_портфеле; комментарий`.
Выручка нужна для расчёта «иск = N% выручки». Синонимы — все варианты названия в СМИ
(с «АК», без кавычек, латиницей).

## 9. Характер агента

Скопировать `AGENTS.md`, `SOUL.md`, `TEMPLATE.md` в рабочую папку агента
(по умолчанию `~/.openclaw/workspace`).

## 10. Расписание (время московское)

```bash
# сбор каждые 3 часа — чтобы ничего не терять: поиск отдаёт только последние ~100 новостей на запрос
openclaw automations create "15 */3 * * *" \
  --name "Авиа: сбор" --tz "Europe/Moscow" \
  --command "python3 collector.py collect --days 3" \
  --command-cwd "$HOME/aviation-monitor"

# справка каждый день в 08:00
openclaw automations create "0 8 * * *" \
  "Подготовь ежедневную справку за вчера по правилам AGENTS.md и шаблону TEMPLATE.md. Сначала запусти сбор: python3 ~/aviation-monitor/collector.py collect --days 2" \
  --name "Авиа: утренняя справка" --tz "Europe/Moscow" \
  --session isolated --announce --channel telegram --to "<твой Telegram ID>"
```
При первом запуске OpenClaw спросит разрешение на запуск команды — ответить «Always allow».

## Проверка готовности

- [ ] `collector.py check` — работает большинство источников
- [ ] `collector.py collect` → `collector.py stats` показывает новости
- [ ] команда в Telegram «справка за вчера» → справка по шаблону, у каждого пункта ссылка
- [ ] на следующее утро в 08:00 справка пришла сама
- [ ] через неделю: «справка за неделю» собирается из архива
- [ ] перевыпустить токен бота (@BotFather → /revoke) и заменить его на сервере — старый засвечен в переписке

## Ограничения (честно)

- **Прошлые периоды до запуска:** архив копится с первого дня работы. Справка за прошлый год
  будет неполной: поиск отдаёт ограниченное число старых новостей. Полная история — с даты запуска.
- **Суды и выручка** берутся только из новостей и из твоей таблицы. Агент не проверяет
  картотеку арбитражных дел и отчётность сам — это отдельный модуль (этап 2).
- Отбор по ключевым словам грубый, итоговое решение «важно / не важно» принимает модель.
  Первые 1–2 недели сверяй справки с тем, что видишь сам, и правь списки слов в `sources.json`.
