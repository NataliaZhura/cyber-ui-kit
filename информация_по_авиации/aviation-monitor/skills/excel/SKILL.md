# Паспорт навыка «Excel»

## Когда применять
Владелец прислал в чат файл `.xlsx` / `.xls` / `.csv` или просит «занести в таблицу», «посчитать», «проверить модель»,
«что на графике», «выгрузить в Excel».

## Где файлы
- Входящий файл из чата скопируй в `~/aviation-monitor/excel/in/` (имя — как у владельца).
- Результат — **всегда новый файл** в `~/aviation-monitor/excel/out/ГГГГ-ММ-ДД_<тема>.xlsx`.
  **Исходный файл никогда не перезаписывай**: при сохранении через openpyxl пропадают графики и часть оформления.
- Готовый файл пришли владельцу: `cd ~/aviation-monitor && python3 share.py tg owner excel/out/<файл>.xlsx`.

## Инструменты (`~/pw/bin/python xl.py …`)
| Задача | Команда |
|---|---|
| Что в файле: листы, формулы, скрытые листы, графики, внешние ссылки | `xl.py info <файл>` |
| Прочитать таблицу | `xl.py dump <файл> [лист] [A1:H40]` |
| Проверить финмодель | `xl.py check <файл>` |
| Отчётность РСБУ по кодам строк → коэффициенты | `xl.py codes <файл>` |
| Графики: тип, название, откуда данные | `xl.py charts <файл>`, затем `dump` по диапазону данных |
| Свой расчёт или новая таблица | Python с `openpyxl` / `pandas` через `~/pw/bin/python` |

## Задачи
1. **Занести данные / посчитать.** Новый лист или файл; в итоговых ячейках оставляй **формулы Excel** (не только
   числа), чтобы владелец видел, как посчитано. Подписи и единицы (млрд ₽, тыс. ₽) — в заголовках.
2. **Загрузить отчётность.** `xl.py codes` → проверь, какой столбец — какой период → внеси в `finance.csv`
   (компания;стандарт;уровень;период;тип;…; суммы в млрд ₽) — она попадёт в карточку и `checko.py profile`.
3. **Коэффициенты** — по навыку `fin-assessment`; формула и подставленные числа рядом с результатом; нет данных — «н/д».
4. **Проверка финмодели.** `xl.py info` + `xl.py check`, затем по существу:
   - баланс сходится (активы = капитал + обязательства) по каждому периоду;
   - денежный поток: начальный остаток + движение = конечный остаток;
   - допущения (рост, ставка, курс, загрузка, цена топлива) — где заданы и реалистичны ли (сравни с отраслью);
   - покрытие платежей по годам — где опускается ниже 1,0;
   - «зашитые» числа, ошибки, внешние ссылки, скрытые листы — из `check`.
   Ответ: 3–5 главных замечаний по убыванию важности, у каждого — лист и ячейка.
5. **Графики.** Не описывай картинку «на глаз»: возьми диапазоны из `xl.py charts`, прочитай числа через `dump`
   и скажи, что показывает график (рост/падение, на сколько, где перелом). Если график прислан картинкой —
   опиши его и пометь «по изображению, числа приблизительные».

## Правила
- Цифры — только из файла или расчёта; ничего не дописывай «для красоты».
- Значения формул берутся из сохранённого Excel; если у формулы нет значения — «н/д, пересчитайте файл в Excel».
- Файлы владельца не пересылай никому, кроме него.
