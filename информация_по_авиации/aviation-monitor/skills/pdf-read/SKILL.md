# Чтение PDF

Все команды — на сервере, файл никуда не отправляется. Программа: `~/aviation-monitor/pdfread.py`.

1. Сохрани присланный файл в `~/aviation-monitor/pdf/in/` (тестовый пользователь — `~/aviation-monitor/excel_tester/in/`).
2. `~/pw/bin/python ~/aviation-monitor/pdfread.py info <файл>` — если «похоже на СКАН», скажи прямо:
   «Это скан без текстового слоя, прочитать цифры не могу — пришлите PDF с текстом или Excel». Не угадывай цифры.
3. По задаче:
   - **Отчётность:** `pdfread.py codes <файл>` → строки РСБУ (1600, 1300, 2110, 2400…) и коэффициенты.
     Затем — оценка по навыку `fin-assessment` и правилам «Справка по компании» в AGENTS.md.
   - **Таблицы:** `pdfread.py tables <файл> [страницы 1-5]` → `<файл>_таблицы.xlsx`; дальше можно навыком `excel`.
   - **Договор, обзор:** `pdfread.py text <файл> [1-10]` → `<файл>.txt`; читай по частям, большой документ —
     сначала оглавление и нужные разделы.
4. Если программа пишет «⚠ Таблица без линий» — сверь 2–3 числа с текстом PDF (`text`) до выводов.
5. Проверь, что первый столбец значений — последний период (в формах порядок бывает разный); укажи период.

## Правила
- Цифры — только из файла; чего нет — «н/д». Проценты к уплате (2330) в формах со знаком минус — программа
  считает покрытие по модулю, это правильно.
- Источник в ответе: название документа, пользователь его прислал. Отраслевые материалы — «из открытых источников».
- Результат-справку отдавай по правилам AGENTS.md («Как отдавать справку» — PDF через `share.py report`).
