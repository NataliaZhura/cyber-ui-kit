# Прогноз рынка авиации (команда /forecast)

Расчёт — только программой `~/aviation-monitor/market.py` (запуск из `~/aviation-monitor`), не «в уме».
Прогноз — **оценка, не факт**: так и пиши. Источники — словом «ссылка»; данные по вертолётам — «из открытых
источников и госзакупок (ЕИС)», имя автора отраслевых материалов не называй никогда.

## Что делать по пунктам подменю
1. `python3 market.py brief` → перескажи в 6–8 строк: самолёты (маржа отрасли сейчас → 2030, в стрессе), вертолёты
   (цена часа против себестоимости нового вертолёта), 3–4 новости, которые могут изменить картину, со ссылками.
   В конце: «Подробнее: 2 — самолёты, 3 — вертолёты, 4 — новости».
2. `python3 market.py forecast` → только блоки «✈️ Самолёты» трёх сценариев: строками по годам (2026, 2028, 2030),
   светофор, вывод в 2 строки: что сильнее всего давит на маржу (керосин, зарплаты, ремонты, спрос).
3. `python3 market.py forecast` → только блоки «🚁 Вертолёты»: разрыв цены часа и себестоимости нового вертолёта по
   годам; вывод: окупается ли обновление парка без господдержки. Подробнее — `/flighthour`.
4. `python3 market.py news --days 30` → по каждому драйверу: куда давит (хуже/лучше для отрасли) и 1–2 новости со
   ссылкой. Новости с баллом ниже 5 не показывай.
5. `python3 market.py now` → опорные цифры с источниками.
6. `python3 market.py forecast --xlsx excel/out/прогноз_рынка.xlsx` → файл тому, кто спросил.

## Новости, меняющие картину
Утром и в «Итогах недели» смотри `python3 market.py news --days 7`. Если в новости **есть цифра**, которая меняет
допущение сценария (цена керосина, ключевая ставка, пассажиропоток, тарифы, зарплаты, ремонты), — предложи
**владельцу** поправку одной строкой: «керосин 2026: 12% → 18% по новости <ссылка> — учесть?». После «да» —
`python3 market.py set <драйвер> <год> <значение> "<ссылка>"`. Гостю поправки не предлагай и сам их не вноси.
Без цифры в источнике поправку не предлагай — только упомяни новость как риск.
