# Лётный час: порядок ответа (команда /flighthour)

Все расчёты — программой `~/aviation-monitor/fh.py` (запуск из `~/aviation-monitor`), не «в уме». Суммы — без НДС.
Данные владельца (`fh_base.csv`, `fh_contracts.csv`, `fh_drivers.csv`) никому не пересылай файлами; в ответе — только
итоговые цифры. Источник структуры затрат и цен — «из открытых источников и госзакупок (ЕИС)»; имя автора
отраслевых материалов не называй никогда.

## Подменю
На `/flighthour` без уточнений ответь сразу, ничего не запуская:
«Лётный час — что показать?
1 — из чего складывается себестоимость часа Ми-8 (старый парк и новый вертолёт) и что на неё сильнее всего влияет
2 — цены часа в госконтрактах и «ножницы»: где цена ниже себестоимости
3 — светофор: индекс расходов и доходов сейчас
4 — прогноз до 2030 года: базовый сценарий и «ножницы»
5 — калькулятор сделки: окупает ли тариф затраты и лизинг, минимальная ставка для DSCR, справедливая ставка
6 — какой должна быть ставка при разном налёте
Ответьте цифрой.»

## Что делать по пунктам
1. `python3 fh.py base` → таблица статей и «вес драйверов». Вывод в 3 строки: три главных рычага для нового
   вертолёта и для старого парка; ключевая ставка действует через лизинг.
2. `python3 fh.py prices` → по видам работ: медиана, доля контрактов ниже себестоимости нового вертолёта и старого
   парка. Вывод: какие работы не окупают обновление парка.
3. `python3 fh.py index` → индекс расходов, индекс доходов, светофор по видам работ. Если драйверы давно не
   обновлялись (строка «Нет данных по драйверам») — так и скажи.
4. `python3 fh.py forecast --xlsx excel/out/лётный_час_прогноз.xlsx` → оба сценария, разрыв цены и себестоимости по
   годам, допущения строкой. Всегда помечай: «прогноз — оценка». Excel — тому, кто спросил.
5. Вопросы по одному: налёт (ч/мес) → ставка часа → цена вертолёта и аванс → ставка и срок лизинга → расходы без
   ТОиР и ТОиР на час (есть модель — возьми из неё и покажи ячейки; нет — предложи базу: `fh.py base`, новый
   вертолёт без строки «Лизинг») → WACC (спроси, не угадывай) → порог DSCR (нет — 1,2, «рабочий порог»).
   `python3 fh.py calc --opex … --mro … --hours … --rate … --price … --lease … --term … [--advance …] --wacc …
   --dscr … --xlsx excel/out/лётный_час_расчёт.xlsx`.
   Ответ: себестоимость часа; а) окупает ли тариф (запас или дефицит, минимальная ставка для DSCR, минимальный
   DSCR и год); б) справедливая ставка (NPV = 0); пять главных факторов из таблицы «что сильнее всего двигает».
6. Как пункт 5, затем таблица «ставка при разном налёте» из вывода `fh.py calc`.

## Обновление драйверов
Новость о керосине, ключевой ставке, зарплатах лётного состава, ценах ремонтов или аэропортовых сборах с цифрой —
`python3 fh.py driver <керосин|зарплата|тоир|аэропорт|инфляция> <ГГГГ-ММ> <рост за месяц, %> "<ссылка>"`;
ключевая ставка — уровнем: `python3 fh.py driver ключевая <ГГГГ-ММ> <ставка, %> "<ссылка>"`. Без ссылки не записывай.
Покажи владельцу, что записал.

## Итоги недели
В «Итоги недели» добавь одну строку из `python3 fh.py index --short` (светофор лётного часа).
