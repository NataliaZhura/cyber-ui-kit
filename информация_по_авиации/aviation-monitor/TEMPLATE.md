# Шаблон справки

Справка строится командой `collector.py export … --out файл.html` (для людей: браузер, печать в PDF)
или `--out файл.md` (для агента). Агент дописывает сверху раздел «Главное» и выводы по каждому разделу.

```
<КОМПАНИЯ / АВИАРЫНОК>: МОНИТОРИНГ НОВОСТЕЙ
Период: 01.10.2026 — 12.10.2026 · Выгрузка: 13.10.2026 08:00 МСК · Сюжетов: 24 (публикаций: 61)

ГЛАВНОЕ (3–7 пунктов, самое значимое для решения о финансировании)

1. Суды и споры
   1.1 🔴 <заголовок> — дата, [ССЫЛКА](адрес); сумма иска и доля от выручки 2024, если известны
2. Слияния и поглощения
3. Самолёты: парк, ресурс, ремонт          ← имущественный риск по самолётам
4. Вертолёты и БПЛА                         ← имущественный риск по вертолётам и БПЛА
5. Правительство и регулирование
6. Санкции и геополитика
7. Финансы: займы, кредиты, размещения
8. Прочее
```

Правила:
- Нумерация сквозная внутри раздела: 3.1, 3.2 …
- Пустой раздел = «Существенных новостей нет» (видно, что его проверили).
- Дата и время — по Москве, в формате ДД.ММ.ГГГГ ЧЧ:ММ.
- Одна новость из разных источников — один пункт, остальные источники в строке «Также писали».
- Приоритет 🔴/🟡/⚪ — сортировка по ключевым словам, а не оценка кредитного риска.
  Оценку риска агент формулирует словами в «Главном», со ссылками на факты.
