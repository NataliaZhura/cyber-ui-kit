# Информация по авиации

## aviation-monitor — агент мониторинга новостей авиарынка

Ежедневная справка в Telegram (08:00 МСК) для инвестора и кредитного комитета: суды и долги
эксплуатантов, допуск к полётам, простой и ремонт парка (дальне- и ближнемагистральные самолёты,
вертолёты, БПЛА), производители и поставки, регулирование. Справки за месяц, квартал и год — из архива.

Состав:
- `SETUP.md` — пошаговый запуск на сервере (OpenClaw + Telegram)
- `collector.py` — сборщик новостей в архив SQLite (только стандартный Python)
- `sources.json` — источники и ключевые слова по активам и рискам
- `watchlist.csv` — список компаний (шаблон; реальный список сюда не коммитить, если репозиторий публичный)
- `AGENTS.md`, `SOUL.md`, `TEMPLATE.md` — правила, тон и шаблон справки агента
