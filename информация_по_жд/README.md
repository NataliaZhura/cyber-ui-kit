# Информация по ЖД

## railway-monitor — агент «ЖДуша» (@zhdusha_bot)

Ежедневная справка в Telegram (08:45 МСК) по рынку **полувагонов и крытых вагонов** в России:
ставки аренды и предоставления, погрузка по грузам, парк и ремонт, тарифы РЖД, суды и сделки операторов.

Устроен как «Ави» (`информация_по_авиации/aviation-monitor`) и работает на том же сервере вторым агентом OpenClaw.
Проверка компаний (Checko, 1С:Контрагент) и PDF берутся из комплекта «Ави», без копий.

Состав:
- `SETUP.md` — запуск на сервере рядом с «Ави»
- `collector.py` — сборщик новостей (тот же, что у «Ави»; ключи `domain_words`, `domain_channels`)
- `sources.json` — ленты, 9 Telegram-каналов, ЖД-слова, разделы справки
- `AGENTS.md`, `SOUL.md`, `TEMPLATE.md` — правила, тон и шаблон справки
- `send.py` — отправка файлов владельцу через бота ЖДуши
- `openclaw_setup.py` — подключение второго агента и бота (plan / apply / check / undo / sync)
- `zmenu.py` — меню и описание @zhdusha_bot
- `guest.py` (запасной вариант, сейчас не нужен) — ещё один тестовый пользователь «Ави» со своим агентом и папками (plan / apply / jobs / off)
- `zguest.py` — гость «ЖДуши» (свой агент, без Argus, копии владельцу); `swap.sh` — Анастасия в ЖДушу, Владислав в Ави
- `watchlist_template.csv` — формат списка компаний (реальный список — только на сервере)

**Не коммитить** (репозиторий публичный): `watchlist.csv`, выпуски Argus и цифры из них (`private/`), токены.
