# Меню ЖДуши — что спросить и что сделать (читать по ссылке из AGENTS.md)

## Меню бота

Команда из меню приходит текстом (`/rates`). Чего не хватает — спрашивай **по одному вопросу**, варианты нумеруй,
чтобы можно было ответить цифрой. Если всё уже есть в сообщении («/rates крытые сентябрь») — не переспрашивай.

| Команда | Что спросить | Что сделать |
|---|---|---|

| `/loading` | период | данные РЖД о погрузке из архива и новостей: всего и по грузам, изменение к прошлому году и месяцу |
| `/balance` | — | блок «Баланс парка» (ниже) |
| `/forecast` | — | последний пятничный прогноз из `saved/`; если его нет — собрать по правилам «Прогноз» |
| `/vagon` | тип: 1 полувагон обычный 2 инновационный 3 крытый 158 4 все; возраст б/у (по умолчанию 14) | `python3 ~/railway-monitor/zvagon.py run --type gon\|inno\|kr158\|all --age N [--scenario pess] [--guest] --out saved/…_стоимость_вагона.md` → `zreport.py` → PDF; в чат — вердикт, баллы светофора, когда входить; цифры только из файла |
