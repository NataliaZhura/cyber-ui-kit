# Шаблон утренней справки ЖДуши

**Цель — руководитель понимает рынок за 3 минуты.** Отдельно полувагоны, отдельно крытые.
Каждая строка — факт или вывод с цифрой. Без вступлений, без пересказа новостей.

Объём: сообщение в чат — **до 1 500 знаков** (только «Главное» и по 2 строки на тип вагона);
PDF — **не больше 2 страниц**. Новостей в справке — **не больше 3 на тип вагона и 3 общих**, остальное — в архив.

```
ЖД-РЫНОК · 16.10.2026 (данные на 08:30 МСК)

ГЛАВНОЕ
1. <самое важное за сутки — 1 строка, с цифрой>
2. …
3. …

━━ ПОЛУВАГОНЫ ━━
Ставка аренды:    610–670 руб./сут (спот, 69 т) · к прошл. мес. ↑ +9% · к году ↓ −50% · Argus, мар. 2026
Ставка 75 т:      850–910 руб./сут · ↑ +2%
Тех. рейс:        Кузбасс–Восточный 77,5–81 тыс. руб./ваг · ↑ +3%
Прогноз ставок:   неделя → без изменений · месяц ↑ +3–5% (оценка: экспорт угля, отстой парка)
Грузопоток:       уголь 52,9 млн т янв–фев ↓ −6,7% г/г · металлы ↑ · стройгрузы сезонно ↓

Новости (≤3):     • <факт> → <влияние одной строкой>

━━ КРЫТЫЕ ━━
Ставка 138 м³:    1 540–1 590 руб./сут · ↓ −0,3% · Argus, мар. 2026

Прогноз ставок:   неделя → · месяц ↑ сезонно (стройгрузы, ЦБП с весны)
Грузопоток:       зерно / ЦБП / стройгрузы / ТНП — изменения и прогноз

━━ КОМПАНИИ ━━ (только если есть события)

```

## Правила

- **Стрелки:** ↑ рост · ↓ снижение · → без изменений. Динамика — всегда в %, с периодом сравнения («к прошл. мес.», «к году»).
- **Ставки:** у каждой — источник и месяц данных, «без НДС», если не указано иное. Свежих нет — пиши дату последних
  («Argus, мар. 2026 — новее нет»), не подставляй старую цифру как сегодняшнюю.
- **Баланс парка** — одно слово крупно (ПРОФИЦИТ / БАЛАНС / ДЕФИЦИТ) + тренд (растёт / сокращается) + 1 строка оснований.
- **Прогноз** — направление и порядок (↑ +3–5%), основание в скобках, пометка «оценка». Без основания прогноз не давать.
- **Новость** — одна строка: факт → влияние (на ставки / грузопоток / компании) · сила · срок. Подробный разбор — только в PDF
  и только для новостей с силой «высокая».
- **Без повторов:** одно событие — один пункт; что было в справках за 3 прошлых дня — не повторять, только «Обновление к ДД.ММ».
- Цифры в примере — образец формата, а не данные: каждый раз брать из источников.
