# Утренние новости ЖДуши (каждый день 08:45 МСК)

Как у «Ави»: новости за вчера, отобранные и с влиянием. **Не справка по рынку** — справки по рынку полувагонов и
крытых делаются отдельно по запросу (`/poluvagony`, `/krytye`, шаблон MARKET.md).

Порядок: `python3 ~/railway-monitor/collector.py collect --days 2` → `python3 collector.py export --from <вчера> --to <вчера>
--new --out saved/ГГГГ-ММ-ДД_новости.md` → отбор → сообщение в чат.


## Правила

- **Каждое событие и каждая цифра — один раз на всю справку** (см. AGENTS.md «Каждое событие — ровно один раз»).
- **Цепочка «вагон → порт → судно»:** проблема в море или порту (закрытие, атака, нет судов, рост фрахта, квота) —
  это новость про вагоны: укажи, какой тип вагона теряет спрос (зерновозы, платформы, полувагоны под уголь) и куда уйдёт
  груз (отстой, автотранспорт, обход через другой порт, контейнеры в полувагонах).
- **Параметры рынка (рубли в прогнозе):** если в новостях есть цифра — квота на экспорт зерна, закрытие порта и срок, рост фрахта, доля зерна на автотранспорте, доля контейнеров в полувагонах, импорт контейнеров, скидка РЖД для платформ — запиши её: `python3 ~/railway-monitor/zevents.py set grain.quota_cut=<%> grain.port=<Порт>:<мес> grain.freight=<%> grain.truck=<%> fit.to_gondola=<%> fit.port=<Порт>:<доля %>:<мес> fit.import=<%> fit.discount=<%>` (только то, что есть в новости; порт открылся — `grain.port=<Порт>:0`). Без цифры — не записывай. В конце справки одна строка: «Учтено в прогнозе: …» (вывод `zevents.py show`).
- **Не больше 10 новостей**, каждая — 1–2 строки: `факт → влияние`, затем «Влияние: …, проявится: …» простыми словами. Пустой раздел — не выводить.
- В справку попадает только то, что влияет на ставки, грузопоток, баланс парка, стоимость вагонов или компании
  из списка. Остальное — в архиве.
- **Без повторов:** одно событие — один пункт; что было в новостях за 3 прошлых дня — только «Обновление к ДД.ММ».
- Нет существенных новостей — одна строка: «Существенных новостей за 15.10 нет».
- Цифра только из Telegram — «по данным канала …, не подтверждено».

Ссылки — только словом [ССЫЛКА](https://…), по одной на новость; голые адреса и списки ссылок не писать.
