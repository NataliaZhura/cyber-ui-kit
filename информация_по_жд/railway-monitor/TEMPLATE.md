# Шаблон справки ЖДуши

Справка строится командой `collector.py export … --out файл.md`. Агент дописывает сверху «Главное»,
блок «Ставки» и выводы по разделам.

```
РЫНОК ПОЛУВАГОНОВ И КРЫТЫХ ВАГОНОВ: МОНИТОРИНГ
Период: 14.10.2026 · Выгрузка: 15.10.2026 08:45 МСК · Сюжетов: 18

ГЛАВНОЕ (3–5 пунктов): что сильнее всего повлияет — на что / на кого / масштаб / срок

СТАВКИ (только с источником, периодом и «с/без НДС»)
  Полувагон 69 т, спот · Полувагон 75 т · Крытый 138 м³ · Крытый 158 м³ · тех. рейс по маршрутам
  Источник ставок: последний выпуск Argus из private/argus/ (только для внутреннего использования),
  открытые: РЖД-Партнёр, ПГК/ИЦО через СМИ. Разные методики не сводить в одну цифру.

1. Ставки и спрос на вагоны
2. Погрузка и грузы        ← уголь, металлы, стройгрузы, щебень (полувагоны); стройгрузы, ЦБП, зерно, ТНП (крытые)
3. Парк: ремонт, отстой, производство
4. Тарифы и регулирование
5. Суды и споры
6. Слияния и поглощения
7. Финансы: займы, кредиты, размещения
8. Инфраструктура и происшествия
9. Санкции и геополитика
10. Прочее

ЧЕГО НЕТ В СПРАВКЕ — какие данные не найдены и где их взять
```

Правила:
- Нумерация сквозная внутри раздела: 1.1, 1.2 …; пустой раздел = «Существенных новостей нет».
- Дата и время — по Москве, ДД.ММ.ГГГГ ЧЧ:ММ. У каждого пункта — ссылка.
- Одна новость из разных источников — один пункт, остальные в строке «Также писали».
- Приоритет 🔴/🟡/⚪ — сортировка по ключевым словам, а не оценка кредитного риска.
